# Todo Paper View and Per-Row Editing Design

## Goal

Todo 纸张打开后默认只用于查看。用户明确点击某一条文字行或可见空白横线时，才进入该行的编辑状态。

本次改动同时修复输入或删除过程中光标跳回第一行开头的问题，并微调纸张尺寸与固定信息的视觉比例。

## Interaction Model

### Initial state

- 打开纸张时不自动聚焦任何 textarea。
- 所有已有内容以普通查看状态显示。
- 纸张内所有可见空白横线都可以点击并写入。
- 打开纸张本身不得触发脏状态。

### Entering edit mode

- 点击具体文字行，只激活该行。
- 点击具体空白横线，只激活对应空白行。
- 同一时间最多只有一行处于编辑状态。
- textarea 出现后，光标应尽量落在用户实际点击的文字位置。
- 不再使用第一行自动聚焦作为兜底行为。

### Leaving edit mode

- 点击另一行时，上一行退出编辑，新行进入编辑。
- 点击纸张内不属于行的区域时，当前行退出编辑。
- 当前内容保留在编辑器状态中。
- 关闭纸张时继续沿用现有的统一保存流程。

### Blank rows

- 编辑器生成足够覆盖纸张可见正文区域的空白行。
- 每条可见空白横线都可以独立点击编辑。
- 未填写内容的空白行不写入本地存储。
- 空白行写入文字后转为正式 Todo 条目。
- 删除正式条目的全部文字后，该条目在保存规范化时被移除。

## Focus and Caret Stability

当前 bug 的表现是输入、删除或重渲染后，焦点跳回第一行开头。

修复要求：

- 移除打开纸张时调用 `focusFirstRow` 的行为。
- 纸张打开时只聚焦 dialog 容器，不聚焦输入框。
- 编辑器重渲染不得主动修改当前活动行。
- 文本变化、自动高度变化、状态切换和新增空白行不得重置 selection。
- 仅在用户点击某行时创建并聚焦该行 textarea。
- 切换到另一行时，才允许显式改变焦点。
- 必要时在 DOM 切换前记录点击位置，并在 textarea 挂载后恢复光标位置。

## Rendering Strategy

每行使用独立的查看态和编辑态：

- 查看态渲染文本内容或空白可点击区域。
- 编辑态渲染 textarea。
- 行状态按钮继续独立存在并支持 pending、completed、record 循环。
- 当前活动行由稳定的 row id 标识，不使用数组第一项或索引作为焦点来源。
- 空白行同样拥有稳定 id，避免输入时重建整组行导致焦点丢失。

## Visual Adjustments

- 删除 textarea 聚焦时出现的下划线、阴影或其他额外图案。
- 右下角签名颜色略微变浅。
- 左上角日期字号略微增大。
- 纸张宽度相对当前值减少约 15px。
- 纸张高度相对当前值减少约 24px。
- 上下固定区域压缩到容纳日期、签名和错误提示所需的最小高度。
- 正文仍是唯一纵向滚动区域。
- Calendar 的结构、尺寸、位置和样式保持不变。

## Save and Error Behavior

- 行退出编辑不立即写入 localStorage。
- 关闭纸张时，如果内容发生变化，先保存再关闭。
- 保存失败时纸张保持打开，当前编辑内容不得丢失。
- 空白行不参与最终存储。
- L 和 G 的数据继续独立保存和刷新预览。

## Tests

新增或调整测试以覆盖：

1. 打开纸张后没有 textarea 自动获得焦点。
2. 点击已有文字行后，仅该行进入编辑状态。
3. 点击可见空白行后可以输入并生成正式条目。
4. 点击纸张其他区域后退出当前行编辑。
5. 从第二行或后续行输入和删除时，焦点不会跳到第一行。
6. 输入后重渲染仍保留当前行与 selection。
7. 未填写的空白行不会写入存储。
8. 删除为空的正式条目在保存时被移除。
9. 编辑态没有额外下划线或阴影图案。
10. 纸张尺寸、日期字号和签名颜色符合新视觉要求。
11. 原有关闭保存、失败保留、L/G 隔离和焦点恢复测试继续通过。

## Non-Goals

- 不引入显式的全局编辑模式按钮。
- 不增加后端 API。
- 不修改 Calendar。
- 不改变 Todo 状态的三态语义。
- 不在每次离开单行时立即持久化。
