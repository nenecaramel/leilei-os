# Home Records Grid Design

## Scope

Only adjust the four Records module cards on Home.

## Layout

- Change the four cards to a 2 × 2 grid.
- Use an 8px horizontal gap and a 10px vertical gap.
- Keep the grid at full Home content width.
- Align the left and right outer edges with the Todo and Calendar cards.
- Keep the order: Memory, Diary, Task, Universe.

## Cards

- Set each card height and minimum height to 35px.
- Center the label horizontally and vertically.
- Keep the existing border, radius, color, typography, links, and interaction states unchanged.

## Non-goals

Do not change Records heading spacing, Todo, Calendar, navigation, or card content.
