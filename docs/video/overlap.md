# 《重叠》—— 制作交接单 v3

给本地执行的 Claude。这是单个视频，不是系列。v3 完全替换之前「梦」主题的 v1/v2。

- **主题（A）**：那些你以为只属于自己的念头，几十万年来一直在一个又一个大脑里醒来——这一次，醒在了你身上。
- **结尾（C）**：第一个想到它的人早已不在，最后一个想到它的人还没出生。
- 文案已由主人定稿，**不要改字**。动效、配色、字号、画面可在样片后由主人调整。
- 画面只用代码绘制和公有领域图片，**不使用 AI 生成的素材**。

## 0. 规格

| 项 | 值 |
|---|---|
| 平台 | 抖音，横屏 |
| 画幅 | 1920×1080，30fps |
| 时长 | 158 拍；72 BPM 时约 132 秒，80 BPM 时约 119 秒 |
| 声音 | 只有 BGM，无人声、无音效 |
| 编码 | 成片 H.264 CRF 18，AAC 320k；每屏的中间文件用 ProRes 422 HQ |
| 响度 | -14 LUFS integrated，-1 dBTP（ffmpeg loudnorm 两遍） |

工程目录：新建独立目录（例如 `~/Videos/overlap/`），用 git 管理，**不要放进 leilei-os**。

## 1. 硬性要求：每一屏、每一帧都能单独改

主人原话：「我需要每一帧都可以单独调整，不能说改这一帧这一段的画面要整个视频全部重做。」以下各条全部必须遵守。

1. **一屏一个组件、一个配置文件**：`src/scenes/<屏号>/Scene.tsx` + `config.ts`。这一屏的位置、尺寸、透明度、颜色覆盖、屏内时序（以拍为单位）全写在自己的 config 里。共享的 `style.ts` 只放全局变量。
2. **每一帧只属于一个屏**。跨屏的过渡归后一屏（入场方）渲染；屏与屏之间是硬切点，可以单独渲染再拼接。
3. **确定性**：禁止 `Math.random`、`Date`、逐帧累积的状态或物理模拟。粒子、星空、3D 旋转、喷绘颗粒都必须是 `f(全局帧号, 种子)` 的纯函数（随机数用 Remotion 的 `random(seed)`）。
4. **单帧微调**：每屏 config 里有 `keyframes` 覆盖数组 `{ frame（屏内帧号）, prop, value }`，在相邻关键帧之间插值。每屏参数用 Zod schema 声明，可以在 Remotion Studio 侧栏里调整并保存回代码。
5. **素材原件不动**：原图放在 `assets/src/`，调色、裁切、推镜全部在渲染时完成。
6. **增量渲染脚本** `scripts/render.ts`：
   - 对每屏计算哈希，输入包括：该屏代码、config、声明的依赖、`style.ts`、用到的素材、该屏区间内的节拍时间。
   - 只重渲哈希变了的屏，输出到 `out/scenes/<屏号>.mov`。
   - 然后 ffmpeg concat 拼接 → 混入音乐 → 响度标准化 → 编码成 H.264 成片。
7. **跨屏依赖写进 config 的 `deps`**：
   - 背景星空里的「段落星」（见 §3），每段结束后都会出现在之后所有屏的背景里。
   - F1 用到七段所有的画面和前半句。
   - C 屏的光点时间线，在第七段的后半句里先出现过一次。
8. **会导致全片重渲的只有这几种**：换 BGM（节拍变了）、改 `style.ts` 全局变量、改分辨率或帧率。动之前先告诉主人。
9. **审片辅助**：草稿渲染时在画面角上烧录「屏号 / 全局帧号 / 拍号 / 时间码」，成片关闭。每屏每 15 帧截一张图，拼成缩略图总表给主人看。主人反馈的格式是「屏号 / 帧号：……」。

## 2. 工具

1. `npx create-video@latest`（Blank 模板），`npx skills add remotion-dev/skills`。安装 skill 前先读它的 SKILL.md。
2. 3D 用 `@remotion/three`。
3. 字体：`@remotion/google-fonts/NotoSerifSC`（思源宋体）400 / 600；`NotoSansDevanagari`（梵文）；拉丁铭文用 `Cinzel` 或其他大写罗马体，等宽字体用 `JetBrains Mono`。
4. 动效参考：`Vincentwei1021/video-shotcraft` 的 Typography 类配方卡，只克隆到临时目录看，不装成 skill。
5. 节拍分析：Python `librosa`，输出 `beats.json`。

## 3. 视觉系统

### 配色和文字
- 背景 `#0D0C0B`，主文字 `#EDE6DA`，次要文字 `#8A8278`。
- **统一调色**：所有画面都经过同一个 `Grade` 组件：去色 → 双色映射（暗部 `#0D0C0B`，亮部 `#EDE6DA`，略偏暖）→ 颗粒 → 暗角。参数放在 `style.ts`。
- **字号**（1920 宽画布）：
  - 大字（前半句、后半句）：88px
  - 例子的内容行：64px
  - 例子的元信息行（年代 · 地点 · 人物）：56px，用 `#8A8278`
  - 结尾 A、C：96px
- **行宽**：大字每行 ≤16 字；例子内容行每行 ≤22 字、最多 2 行。
- 引号统一用「」。
- **动效**：
  - 进场：淡入 + 上移 12px + 模糊 6px→0，18 帧，缓出，不要弹跳。
  - 退场：淡出 12 帧。
  - 只有第七段「做这个视频的 AI」那句用等宽字体逐字打出，带闪烁光标。

### 每一段的版式（第一到第七段都一样）
1. **前半句**先出现在画面正中；第一个例子进来时，它上移到顶部（y≈0.16），透明度降到 0.7，作为这一段的语境一直留着。
2. **例子一个个叠上来**。每个例子 = 一个画面（大，放在底层）+ 一个标签块（元信息行 + 内容行）。
   - 新画面盖在旧画面上面；旧画面缩到 0.92 倍，透明度降到 0.25，向它自己的方向偏移 40px，**不消失**。
   - 标签块位置轮换：第 1 个在左下（x 0.06–0.46，y≈0.66），第 2 个在右下（x 0.54–0.94，y≈0.66），第 3 个在中下（x 0.25–0.75，y≈0.84）。旧标签保持可读（透明度 0.8），观众可以回头读。
3. **后半句**出现时：所有画面降到 0.12，标签降到 0.25，后半句在正中出现。
4. **段落星**：每段最后 1 拍，这一段所有内容收缩成一个亮点，飞到背景星空里自己的位置，此后一直留在背景里（亮度 0.6，轻微闪烁，闪烁 = f(帧号)）。七段一共留下七颗星；F1 时它们再展开。

## 5. BGM

- **气质**：安静、辽阔、思考感，钢琴为主，加弦乐或铺底音色，新古典 / 氛围风格。**不要人声**。
- **速度**：72–80 BPM，要有清晰的律动，否则节拍检测不准。
- **结构**：
  - 前约 20 秒稀疏。
  - 第 24 拍进入主体段。
  - 第四段可以稍微收一点。
  - 第 120 拍是全片最高点。
  - C 段回落。
  - 第七段末尾的压低用音量自动化做，不要求曲子本身有停顿。
- **长度**：≥140 秒，或者能在小节边界无缝循环。
- **来源**：Pixabay Music（可商用、免署名）。搜索关键词：`ambient piano`、`neoclassical`、`cinematic ambient`、`contemplative`。先挑 3 首给主人试听，主人定。以后要发 YouTube 的话，避开登记了 Content ID 的曲子。不用抖音曲库。
- **对齐流程**：
  1. 选定曲目。
  2. 如有需要，在小节边界剪辑 / 交叉淡化，让结构对上上面那几个拍号。
  3. 用 librosa 输出 `beats.json`。
  4. 所有时间点都从 `beats.json` 取。
- 音乐在最后一步才混进去。只要节拍时间不变，调音量、调淡入淡出都不需要重渲画面。

## 7. 制作顺序

1. 搭工程骨架：按屏拆好的组件、`style.ts`、`Grade` 组件、星空、段落星、增量渲染脚本、审片角标。先用占位的 72 BPM 节拍。
2. 完成 §6 的核对和素材收集。
3. 先做一段（建议第一段）完整的样片给主人看，确认版式和动效后，再做其余各段。
4. 定 BGM，生成 `beats.json`，全片渲染一次。
5. 跑 §8 的审片。
6. 主人逐屏、逐帧提修改，用增量渲染返工。
7. 出成片和封面。

## 8. 审片（成片后开 4 个独立的评审子 agent 同时检查）

1. **可读性**：用手机竖着拿、横屏视频不全屏的状态看，大字和标签都要看清；叠上来的画面不能压住正在出现的文字。
2. **节奏**：每个例子来得及读；后半句停留够长；换屏落在拍上；F1 有冲击力；C 屏不仓促。
3. **准确性**：逐字对照 §6；年代、引号、人名都要对；素材授权都有记录。
4. **审美**：各段版式一致，调色统一，段落星的位置均衡，有没有廉价感。

另外，随机抽 3 屏单独渲染，和整片渲染结果逐帧比对，必须一致。

评审出的问题修完再交给主人。主人在真机上确认后才算完成。
