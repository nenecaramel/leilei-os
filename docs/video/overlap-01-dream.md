给本地执行的 Claude。文案已由主人确认，**不要改字**；动效、配色、字号、画面可在样片后由主人调整。

v2 变更：加入画面层（全部用代码绘制，加公有领域图片），**不使用 AI 生成素材**；工程架构改为按屏独立、可增量渲染。

| 项 | 值 |

## 1. 硬性要求：每一屏、每一帧都能单独改

主人原话：「我需要每一帧都可以单独调整，不能说改这一帧这一段的画面要整个视频全部重做。」以下各条是实现这一点的约束，**全部必须遵守**。

1. **一屏一个组件、一个配置文件**。`src/scenes/S09/` 下放 `Scene.tsx` 和 `config.ts`；这一屏的位置、尺寸、透明度、颜色覆盖、屏内时序（以拍为单位）全写在自己的 config 里。共享的 `style.ts` 只放全局变量（配色、字体、调色参数）。
2. **每一帧只属于一个屏**。跨屏的过渡归后一屏（入场方）渲染；屏与屏之间是硬切点，所以每屏可以单独渲染再拼接，接缝处不会出问题。
3. **确定性**：禁止 `Math.random`、`Date`、任何逐帧累积的状态或物理模拟。所有粒子、数字雨、3D 旋转都必须是 `f(全局帧号, 种子)` 的纯函数（随机数用 Remotion 的 `random(seed)`）。这样单独渲染某一屏，结果和整片渲染逐像素一致。
4. **单帧微调**：每屏 config 里有一个 `keyframes` 覆盖数组 `{ frame（屏内帧号）, prop, value }`，在相邻关键帧之间插值，只改动那一小段，不影响其他地方。每屏的参数用 Zod schema 声明，主人或 Claude 可以在 Remotion Studio 侧栏里拖动调整并保存回代码。
5. **素材原件不动**：原图放在 `assets/src/`，调色、裁切、推镜全部在渲染时完成，改调色不需要重新处理图片。
6. **增量渲染脚本** `scripts/render.ts`：
   - 对每屏计算一个哈希，输入包括：该屏代码、config、它声明的依赖、`style.ts`、用到的素材、该屏区间内的节拍时间。
   - 只重新渲染哈希变了的屏，输出到 `out/scenes/Sxx.mov`。
   - 之后 ffmpeg concat 拼接 → 混入音乐 → 响度标准化 → 编码成 H.264 成片。
   - 改一屏通常只需要重渲这一屏，再花几秒拼接。
7. **跨屏依赖要在 config 里写明**（`deps`），让哈希能算准：
   - 残影：S5 / S6 / S8 / S9 / S10 的引文，会以残影形式出现在它之后、直到 S11 的每一屏 → 改其中一段引文的样式，后面带它残影的屏都要重渲。
   - S12 用到 S3 / S5 / S6 / S8 / S9 / S10 的文字和画面。
   - S13–S15 和 S1–S4 共用一套粒子系统。
8. **会导致全片重渲的只有这几种**：换 BGM（节拍时间变了）、改 `style.ts` 全局变量、改分辨率或帧率。要先告诉主人再动。
9. **审片辅助**：草稿渲染时在画面角上烧录「屏号 / 全局帧号 / 拍号 / 时间码」，成片关闭。每屏每 15 帧截一张图（`npx remotion still`），拼成一张缩略图总表给主人看。主人反馈的格式是「S9 / 帧 1720：……」。

## 2. 工具

1. `npx create-video@latest`（Blank 模板），`npx skills add remotion-dev/skills`。安装 skill 前先读它的 SKILL.md。
2. 3D 用 `@remotion/three`（React Three Fiber）；地图用 `d3-geo` 加 Natural Earth 陆地数据（公有领域）。
3. 字体：`@remotion/google-fonts/NotoSerifSC`（即思源宋体），字重 400 / 600。
4. 动效参考：`Vincentwei1021/video-shotcraft` 的 Typography 类配方卡，只克隆到临时目录看，不装成 skill。
5. 节拍分析：Python `librosa`，输出 `beats.json`。

## 3. 视觉系统

### 文字
- 背景 `#0D0C0B`，主文字 `#EDE6DA`，时代标题和署名 `#8A8278`。
- 字号（1920 宽画布）：正文 96px｜引文 80px｜时代标题 64px｜署名 64px｜「今晚，你。」140px。**不得小于 64px。**
- 每屏 ≤2 行（引文 + 标题 + 署名例外），每行 ≤16 字，居中。
- 引号统一用「」。庄子原文是「胡蝶」，**不要改成「蝴蝶」**。
- **进场**：每行淡入 + 上移 12px + 模糊 6px→0，18 帧，缓出，不要弹跳。
- **退场**：淡出 12 帧。
- **时代标题**：字距 0.3em→0.15em，同时淡入，20 帧。
- **打字**：只有 S3 第二行逐字出现，约 8 字/秒。

### 画面层
- **统一调色**：所有画面都经过同一个 `Grade` 组件：去色 → 双色映射（暗部 `#0D0C0B`，亮部 `#EDE6DA`，略偏暖）→ 颗粒 → 暗角。参数放在 `style.ts`。这样古画、照片和代码图形看起来是同一部片子。
- **亮度上限**：画面上有文字时，画面层最高亮度不超过 35%（每屏可在 config 里覆盖）。文字始终是主角。
- 画面层只属于自己那一屏，屏结束时淡出。**会一直留在画面里的只有引文残影**（见下）。

### 核心母题：残影（重叠感就在这里）
从 S5 开始，每个引文屏结束时，引文块不消失：缩放到 0.55，透明度降到 0.14，模糊 2px，用 1 拍漂移到自己的残影位，之后一直留着，非常缓慢地漂移（每秒 ≤3px，位置是帧号的函数）。

| 引文 | 残影中心（归一化 x, y） |
|---|---|
| 庄子 | (0.25, 0.20) |
| 柏拉图 | (0.75, 0.20) |
| 笛卡尔 | (0.22, 0.80) |
| 普特南 | (0.78, 0.80) |
| 黑客帝国 | (0.50, 0.90) |

当前屏的文字始终在中心区（y 0.38–0.62），不能被残影压住。

## 6. BGM

- **气质**：安静、思考感，钢琴为主，弦乐或铺底音色为辅，新古典/氛围风格。**不要人声**。
- **速度**：68–76 BPM，要有清晰的律动，否则节拍检测不准。
- **结构**：前 ≥15 秒稀疏 → 逐渐展开 → 后段有一处高点。S11 的压低用音量自动化做。
- **长度**：≥100 秒，或者能在小节边界无缝循环。
- **来源**：Pixabay Music（可商用、免署名）。搜索关键词：`ambient piano`、`neoclassical`、`contemplative`、`dreamy piano`。先挑 3 首给主人试听，主人定。若以后要发 YouTube，避开登记了 Content ID 的曲子。不用抖音曲库。
- **对齐流程**：
  1. 选定曲目。
  2. 如有需要，在小节边界剪辑 / 交叉淡化，让主体段从第 20 拍左右开始、最高点落在第 88 拍左右。
  3. 用 librosa 输出 `beats.json`。
  4. 分镜里所有时间点都从 `beats.json` 取。
- **混音**：开头 1 拍淡入；S11 压低 -12dB，S12 第 0 拍回升；结尾 2 拍淡出；最后做响度标准化。
- 音乐在最后一步才混进去。只要节拍时间不变，调音量、调淡入淡出都不需要重渲画面。

## 7. 制作顺序

1. 搭工程骨架：按屏拆好的组件、`style.ts`、`Grade` 组件、增量渲染脚本、审片角标。先用占位的 72 BPM 节拍。
2. 收集素材，写好 `SOURCES.md`。
3. 逐屏实现，每做完一屏就截缩略图总表给主人看。
4. 定 BGM，生成 `beats.json`，全片渲染一次。
5. 跑第 8 节的审片。
6. 主人逐屏、逐帧提修改，用增量渲染返工。
7. 出成片和封面。

## 8. 审片（成片后开 4 个独立的评审子 agent 同时检查）

1. **可读性**：用手机竖着拿、横屏视频不全屏的状态看，每个字都要看清；画面层和残影都不能干扰当前屏的文字。
2. **节奏**：每屏停留时间够读完；换屏落在拍上；只有画面的那几拍不拖沓；S11 → S12 的转折有冲击力。
3. **准确性**：逐字对照第 9 节；标点、「」、「胡蝶」、年份、署名、「（大意）」、地图距离都要对；素材授权都有记录。
4. **审美**：字距、对齐、残影位置是否均衡，各种画面调色是否统一，有没有廉价感。

另外，随机抽 3 屏单独渲染，和整片渲染结果逐帧比对，必须一致（验证第 1 节的确定性要求）。

评审出的问题修完再交给主人。主人在真机上确认后才算完成。
