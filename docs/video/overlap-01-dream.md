## 1. 工具

1. `npx create-video@latest`（Blank 模板），`npx skills add remotion-dev/skills`。安装 skill 前先读它的 SKILL.md。
2. 字体：`@remotion/google-fonts/NotoSerifSC`（即思源宋体），字重 400 / 600。
3. 动效参考：`Vincentwei1021/video-shotcraft` 的 Typography 类配方卡，只克隆到临时目录看，不装成 skill。
4. 节拍分析：Python `librosa`（`beat_track` + `onset_detect`），输出 `beats.json`（每拍秒数数组）。

## 2. 视觉系统

- 背景 `#0D0C0B`，极轻胶片颗粒 + 缓慢呼吸的暗角。
- 主文字 `#EDE6DA`；时代标题/署名 `#8A8278`。
- 字号（1920 宽画布）：正文 96px｜引文 80px｜时代标题 64px｜署名 64px｜「今晚，你。」140px。**不得小于 64px。**
- 每屏 ≤2 行（引文 + 标题 + 署名例外），每行 ≤16 字，居中。
- 引号统一用「」。庄子原文是「胡蝶」，**不要改成「蝴蝶」**。

### 动效
- **进场**：每行淡入 + 上移 12px + 模糊 6px→0，18 帧，缓出，不要弹跳。
- **退场**：淡出 12 帧。
- **时代标题**：字距 0.3em→0.15em，同时淡入，20 帧。
- **打字**：只有 S3 第二行「我现在，会不会也在梦里？」逐字出现，约 8 字/秒。

### 核心母题：残影（重叠感就在这里）
从 S5 开始，每个引文屏结束时，引文块**不消失**：缩放到 0.55，透明度降到 0.14，模糊 2px，用 1 拍的时间漂移到自己的残影位，之后一直留在画面里，并且非常缓慢地漂移（每秒 ≤3px）。

| 引文 | 残影中心（归一化 x, y） |
|---|---|
| 庄子 | (0.25, 0.20) |
| 柏拉图 | (0.75, 0.20) |
| 笛卡尔 | (0.22, 0.80) |
| 普特南 | (0.78, 0.80) |
| 黑客帝国 | (0.50, 0.90) |

当前屏的文字始终在中心区（y 0.38–0.62），不能被残影压住。

## 4. BGM

- **气质**：安静、思考感，钢琴为主，弦乐或铺底音色为辅，新古典/氛围风格。**不要人声**（会和阅读抢注意力）。
- **速度**：68–76 BPM，要有清晰的律动（比如钢琴固定音型），否则节拍检测不准。
- **结构**：前 ≥15 秒稀疏 → 逐渐展开 → 后段有一处高点。S11 的压低用音量自动化做，不要求曲子本身有停顿。
- **长度**：≥95 秒，或者能在小节边界无缝循环。
- **来源**：Pixabay Music（可商用、免署名）。搜索关键词：`ambient piano`、`neoclassical`、`contemplative`、`dreamy piano`。先挑 3 首给主人试听，主人定。若以后要发 YouTube，避开登记了 Content ID 的曲子。**不要用抖音曲库**（没法在本地卡拍，也不能跨平台）。
- **对齐流程**：
  1. 选定曲目。
  2. 如有需要，在小节边界剪辑 / 交叉淡化（ffmpeg `acrossfade`），让主体段从第 20 拍左右开始、最高点落在第 80 拍左右。
  3. 用 librosa 输出 `beats.json`。
  4. 分镜里所有时间点都从 `beats.json` 取。
- **混音**：开头 1 拍淡入；S11 压低 -12dB，S12 第 0 拍回升；结尾 2 拍淡出；最后做响度标准化。

## 5. 实现建议（Remotion）

- 用数据驱动：`storyboard.ts`（各屏的拍区间、文字行、屏内时序、类型）+ `beats.json` → 每个时间点 = `Math.round(beats[i] * fps)`。
- 组件：`Line`（进场 / 退场）、`Screen`、`ResidueLayer`（管理已结束引文的残影，从 S5 开始累积）、`Overlap`（S12）。
- `durationInFrames` 由最后一拍 + 尾巴算出。
- 先出无音乐的 720p 草稿看节奏，再出成片。

## 6. 审片（成片后开 4 个独立的评审子 agent 同时检查）

1. **可读性**：用手机竖着拿、横屏视频不全屏的状态看，每个字都要看清；残影不能干扰当前屏文字。
2. **节奏**：每屏停留时间够读完；换屏落在拍上；S11 → S12 的转折有冲击力。
3. **准确性**：逐字对照第 7 节；标点、「」、「胡蝶」、年份、署名、「（大意）」都要对。
4. **审美**：字距、对齐、残影位置是否均衡，有没有廉价感。

评审出的问题修完再交给主人。主人在真机上确认后才算完成。
